# 🔐 Get Railway MySQL Password

## Quick Answer

The MySQL password is stored in Railway's environment variables. Here's how to get it:

### Method 1: Railway Dashboard (Easiest)

1. Go to your **MySQL service** in Railway dashboard
2. Click **"Variables"** tab
3. Look for **`MYSQLPASSWORD`** - that's your password!

### Method 2: Railway CLI

```bash
# Install Railway CLI if you haven't
npm i -g @railway/cli

# Login
railway login

# Link to your project
railway link

# View all variables (including password)
railway variables

# Or get just the MySQL password
railway variables | grep MYSQLPASSWORD
```

### Method 3: Use Railway Variables Directly

Railway automatically injects MySQL variables. You can use them directly:

```bash
# Connect to MySQL using Railway variables
railway run mysql -u ${{MYSQLUSER}} -p${{MYSQLPASSWORD}} -h ${{MYSQLHOST}} -P ${{MYSQLPORT}} ${{MYSQL_DATABASE}}

# Or run a query directly
railway run mysql -u ${{MYSQLUSER}} -p${{MYSQLPASSWORD}} -h ${{MYSQLHOST}} -P ${{MYSQLPORT}} ${{MYSQL_DATABASE}} -e "SELECT * FROM users;"
```

**Note:** Railway automatically replaces `${{VARIABLE_NAME}}` with the actual value!

### Method 4: Use MYSQL_PUBLIC_URL

Railway also provides `MYSQL_PUBLIC_URL` which is a complete connection string:

```bash
# View the connection string
railway variables | grep MYSQL_PUBLIC_URL

# Use it directly
railway run mysql "${{MYSQL_PUBLIC_URL}}"
```

## Example: View Users

```bash
# Method 1: Using Railway variables
railway run mysql -u ${{MYSQLUSER}} -p${{MYSQLPASSWORD}} -h ${{MYSQLHOST}} -P ${{MYSQLPORT}} ${{MYSQL_DATABASE}} -e "SELECT id, email, name, role FROM users;"

railway run mysql "${{MYSQL_PUBLIC_URL}}" -e "SELECT id, email, name, role FROM users;"
```
